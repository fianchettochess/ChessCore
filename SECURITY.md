# Security Policy

## Supported versions

Security fixes are made on `main` and released from the latest supported
version. Older releases may not receive backports.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting form in this repository's **Security** tab.
If that form is unavailable, contact a maintainer through GitHub without
including sensitive details so a private reporting channel can be arranged.

Reports involving crashes, excessive resource use, or unsafe behavior while
parsing untrusted FEN, PGN, SAN, UCI, or snapshot data are especially useful.
Include the affected version, a minimal reproducer, impact, and any suggested
mitigation when possible. Non-sensitive defects can use the public issue
tracker.
